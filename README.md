# シフト管理アプリ

バイト生がスマホでシフト希望を出し、店長がシフトを作って公開するためのウェブアプリです。

| 画面 | ファイル | 使う人 |
|---|---|---|
| シフト提出 | `index.html` | バイト生 |
| 確定シフト | `view.html` | バイト生・社員 |
| シフト管理 | `admin.html` | 店長 |

## 2つのモード

- **お試しモード**: `js/config.js` の `API_URL` が空のとき。入力内容はその端末のブラウザ内だけに保存されます。
- **本番モード**: `API_URL` にApps ScriptのURLを入れたとき。Googleスプレッドシートに保存され、全員で共有されます。

## スプレッドシートの準備(本番モードにする手順)

1. Googleスプレッドシートを新しく作ります(名前は「シフト管理」など自由)。
2. メニューの「拡張機能」→「Apps Script」を開きます。
3. 最初から入っている内容を全部消し、`gas/Code.gs` の中身を全部貼り付けて保存します。
4. 画面上部の関数の選択で `setup` を選び、「実行」を押します。
   - 初回は権限の確認が出ます。「詳細」→「(安全ではないページ)に移動」→「許可」と進みます。自分で作ったスクリプトなので問題ありません。
5. スプレッドシートに戻ると、シートが3枚できています。
   - **スタッフ**: A2から下に、バイト生の名前を1行に1人ずつ入れます。
   - **提出データ**・**シフトデータ**: アプリが書き込みます。手で触らないでください。
6. Apps Scriptの画面に戻り、「デプロイ」→「新しいデプロイ」を押します。
   - 種類の選択(歯車): 「ウェブアプリ」
   - 次のユーザーとして実行: 「自分」
   - アクセスできるユーザー: 「全員」
7. 「デプロイ」を押し、表示された「ウェブアプリのURL」をコピーします。
8. `js/config.js` の `API_URL: ''` の `''` の中に、そのURLを貼り付けます。

あとから `Code.gs` を書き換えたときは、「デプロイ」→「デプロイを管理」→ 鉛筆マーク →「バージョン: 新バージョン」→「デプロイ」で反映します(URLは変わりません)。

## 毎月の流れ

1. バイト生が `index.html` で来月の希望を出す(締切は前月20日)。
2. 店長が `admin.html` で提出状況を見て、「自動で割り当てる」や名前のタップでシフトを作る。
3. 臨時休業がある日は「休みにする」を押す。
4. 「シフトを公開する」を押す。バイト生・社員は `view.html` で見られる。
5. 画面下の「TimeTree用の出力」からタイトルをコピーして、TimeTreeに登録する。

## 設定を変えるとき

`js/config.js` で変えられます。

- `DEADLINE_DAY`: 締切日
- `REQUIRED`: 1日に必要な人数(早番・遅番)
- `CLOSED_WEEKDAYS` / `CLOSED_NTH_WEEKDAYS`: 定休日
- `STAFF`: お試しモード用の仮の名前(本番モードではスプレッドシートの「スタッフ」シートが使われます)

## 注意

- 合言葉やパスワードはありません。3つの画面とも、リンクを知っていれば誰でも使えます。リンクは店の関係者だけに共有してください。
- 管理画面(`admin.html`)のリンクを知っている人は、誰でもシフトを書き換えられます。管理画面のリンクは店長だけが持つようにしてください。
- 何も付けていない日と、提出していない人は「OFF(入れない)」として扱います。
- 「スタッフ」シートの名前は、リンクを知っている人なら誰でも見られます。気になる場合は名字だけ・あだ名などにしてください。
- 「提出データ」シートの「希望(読みやすい形)」列は確認用です。書き換えてもアプリには反映されません。
